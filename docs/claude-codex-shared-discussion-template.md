# Claude / Codex 共享讨论文档模板

这个模板用于在你、VSCode 里的 Claude、以及我之间传递同一件事的上下文，避免反复解释，也避免把“想法”“事实”“结论”“待决策项”混在一起。

推荐做法：

1. 复制本文件，重命名为 `docs/plans/YYYY-MM-DD-主题-discussion.md`
2. 先把用户原始需求贴进“原始需求”一节
3. 让 Claude 只更新“Claude 区”
4. 让 Codex 只更新“Codex 区”
5. 最终只在“共识 / 分歧 / 决策 / 行动项”里沉淀结果

建议协作约定：

- 不直接覆盖对方的原始结论，优先在自己的区块补充或反驳
- 所有“事实”尽量附文件、代码、数据或测试依据
- 所有“判断”尽量写清楚前提和边界
- 没验证过的内容统一放进“未验证假设”

## 12. 快速使用示例

你可以把下面这段直接发给 Claude：

```md
请只更新这份文档里的“Claude 区”和“共识与分歧”相关内容，不要改写“原始需求”与“Codex 区”。
如果你给出判断，请同时写明：
1. 你的依据是什么
2. 哪些是已确认事实，哪些是推测
3. 你认为最关键的风险和下一步是什么
```

你也可以把下面这段发给 Codex：

```md
请基于当前仓库代码，只更新这份文档里的“Codex 区”“链路检查”“可行性评估”和“行动项”。
不要直接覆盖 Claude 的原始观点；如果不同意，请在“共识与分歧”中写清楚分歧点、依据和影响范围。
```
